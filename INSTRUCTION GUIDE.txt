INSTRUCTION GUIDE


Library Deployment Model

Before Contacting Libraries
1. Create organization name.
2. Create mission statement.
3. Create website.
4. Create email address.
5. Create one-page flyer.
6. Create volunteer signup form.
7. Create meeting agenda template.

Initial Library Contact
1. Call library administration.
2. Ask for meeting room policies.
3. Ask for civic group eligibility.
4. Ask about recurring reservations.
5. Request application forms.


First Meeting
Agenda:
1. Welcome
2. Mission Overview
3. Community Discussion
4. Volunteer Signup
5. Upcoming Projects
6. Closing
After Meeting
1. Publish meeting notes.
2. Publish newsletter.
3. Upload recordings.
4. Recruit volunteers.
5. Schedule next meeting.

Expansion Model
Compliance Recommendations
Follow all library rules.
Avoid implying government endorsement.
Respect facility neutrality policies.
Maintain viewpoint-neutral event access when required by facility rules.
Review applicable federal, state, and local laws before engaging in election-related
advocacy, fundraising, or expenditures.
This package is sufficient to launch a library-centered Digital Citizens Network chapter
system and begin recruiting volunteers, hosting meetings, publishing research, and
building the distributed media network envisioned in the original document.
